# 🦖 Invitación Primer Añito · Arthur Jaziel

Invitación digital interactiva responsive para el primer cumpleaños de **Arthur Jaziel**.

- **Fecha:** Sábado 24 de octubre, 4:00 p.m.
- **Temática:** Dinosaurios baby (paleta verde/crema con hojas selváticas y globos).
- **Ubicación:** [Google Maps](https://www.google.com/maps/place/11%C2%B055'25.8%22S+77%C2%B003'08.1%22W/@-11.9238323,-77.0548324,17z/data=!3m1!4b1!4m4!3m3!8m2!3d-11.9238323!4d-77.0522575?hl=es&entry=ttu&g_ep=EgoyMDI2MTAwNi4wIKXMDSoASAFQAw%3D%3D).

## ✨ Características

- 🥚 **Portada animada:** Huevo que se balancea y se rompe al tocarlo con explosión de confeti en `<canvas>`.
- 🎈 **Cabecera festiva:** Globos animados y personaje ilustrado de Arthur con traje de dinosaurio.
- 🔄 **Foto interactiva con giro 3D:** Marco redondo decorado con hojas y dinos que rota entre dos fotos reales de Arthur.
- ⏱️ **Cuenta regresiva:** Contador de días, horas, minutos y segundos hasta el inicio de la fiesta.
- 📍 **Botón de ubicación:** Acceso directo a Google Maps.
- 📱 **Mobile-first:** Optimizado para smartphones y adaptable a pantallas de ordenador.

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 moderno (Custom Properties, Flexbox, Grid, keyframes, backdrop-filter)
- JavaScript nativo (IntersectionObserver, Canvas API)
- Imágenes optimizadas en formato WebP con fondo transparente
